# 条件
- 各投稿は日本語で70字以内を目安に収める（Xでは日本語1文字を2としてカウントし、上限は280）
- 最初の1文で読者の興味を引く
- 元の動画内容を歪めない。固有名詞や数字は文字起こしにある範囲でのみ使い、不確かなものは断定しない
- 誇張表現（「絶対」「100%」「誰でも」「必ず」など）は使わない
- 動画の文章をそのまま転載せず、要点を自分の言葉で再構成する
- 字幕には誤変換があるため、文脈から自然に補正する

# 切り口（この順で5つ固定）
1. 共感型：読者が「わかる」と感じる書き出し
2. 学び型：動画から得られる具体的な知識を提示
3. 気づき型：見落とされがちな視点を切り取る
4. 刺さる一言型：核心を一言で圧縮する
5. 問いかけ型：読者に考えさせる問いで始める
